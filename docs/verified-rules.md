## What a project must be

- An application that integrates the PayPal developer platform (free sandbox qualifies) together with an AI tool, model or platform of the entrant's choice. PayPal integration must be central.
- Newly created, or significantly updated after the submission period opened, with an explanation of the update.
- Able to be installed and run consistently, and to work as shown in the video and described in the text.
- Any third-party SDK, API or data used must be used within its terms.

## What a submission must contain

1. A text description of features and functionality.
2. Access to a functional demo: either complete setup and run instructions in the repository, or a hosted URL. A mockup or non-functional demo does not count. If the site is private, credentials go in the testing instructions.
3. A public code repository (GitHub, Bitbucket or GitLab) holding all source, assets and instructions, with an open source license file that is detectable at the top of the repository page.
4. A demonstration video under three minutes, public on YouTube, showing the project running on the device it was built for, without third-party trademarks or copyrighted music unless permitted.
5. All materials in English.
6. The project must stay free to test for the sponsor, administrator and judges until the judging period ends.

## Judging

Stage one is pass or fail: the project reasonably fits the theme and reasonably applies the required APIs. Stage two scores five equally weighted criteria:

1. Technological Implementation: depth and skill in using the PayPal Developer Platform and AI tools, a working non-trivial implementation.
2. Design: a complete, coherent product experience.
3. Potential Impact: a credible, specific case for a real problem and a real audience.
4. Innovation/Idea: novelty against existing concepts.
5. Presentation: the video shows the project working end to end and communicates problem, audience and importance.

Ties are broken by the highest score on the first criterion listed, then the next, then a judge vote.

## Prizes

Grand prizes: 1st $12,000, 2nd $8,000, 3rd $5,000. Honorable mentions of $5,000 each: Most Creative, Most Impactful, Best Demo Delivery, Best Use of PayPal + AI, Best Use of Agentic Commerce.

Sponsor prizes, each open only to submissions that use that sponsor's tools: AG Grid (1st $5,000, 2nd $2,000, 3rd $1,000 x3), APIMatic ($1,000 x3 plus six months of a business subscription), Bryntum ($1,000 x3), Channel3 ($1,500), Render (credits: $1,000, $750, $500).

A project can win at most one grand prize and one sponsor prize, or one honorable mention and one sponsor prize.
